# KeycardAnywhere

Плагин для UnicornAPI (серверный фреймворк для SCP: Project 90): двери с уровнем доступа открываются, если подходящая ключ-карта лежит в любом слоте инвентаря. Доставать карту в руки не нужно.

> Версия 1.0.0. Нужен UnicornAPI 1.0.0 или новее. Игра SCP: Project 90 0.4.2 [F05].

## Что делает

Когда игрок нажимает на дверь, плагин проверяет по порядку и вмешивается, только если выполнено всё:

- у двери есть уровень доступа (обычные двери без доступа открывает сама игра);
- игрок жив;
- в руках у него нет подходящей карты (если есть, работает обычная логика игры);
- игрок не SCP (у SCP своя логика дверей);
- игрок не в наручниках (можно разрешить через `AllowWhenCuffed`);
- в инвентаре есть предмет с нужным доступом (доступ сверяется так же, как в игре: точное совпадение уровня двери с правами карты);
- до двери не дальше `MaxDistance` метров (по умолчанию 15, как в игре).

Тогда обычная проверка игры не запускается, а дверь открывается или закрывается так же, как при карте в руках: со звуком, подсветкой кнопки и задержкой. Если дверь сейчас нельзя переключить (заперта, сломана, на задержке, в движении), ничего не происходит.

Если игра или другой плагин уже отменили нажатие, KeycardAnywhere его не трогает.

Ещё плагин публикует для сайта (через WebBridge, раздел `KeycardAnywhere` в `Server.PublicInfo`) описание и настройки: включён ли он и работает ли в наручниках.

## Установка

1. Установлен UnicornAPI.
2. Положить `KeycardAnywhere.dll` в `UnicornAPI/Plugins/`, затем `reload` в консоли или перезапуск.
3. Конфиг создаётся сам: `UnicornAPI/Configs/KeycardAnywhere.json`.

## Настройки

| Поле | По умолчанию | Что делает |
|---|---|---|
| `Enabled` | `true` | включить плагин |
| `AllowWhenCuffed` | `false` | работать и для игрока в наручниках (в самой игре закованный не может пользоваться инвентарём) |
| `MaxDistance` | `15` | максимальная дистанция до двери, м |
| `Debug` | `false` | писать в лог сервера каждое открытие картой из инвентаря: ник, дверь, уровень доступа, какая карта и чем кончилось |

## Сборка

Нужно: .NET 6 SDK или новее и папка игры с BepInEx (запущенным хотя бы раз) и установленным UnicornAPI.

```
dotnet build -c Release -p:GameDir="D:\Steam\steamapps\common\SCP Project 90"
```

Без `-p:GameDir` сборка ищет `./libs` с той же структурой (`libs/BepInEx/core`, `libs/BepInEx/interop`, `libs/BepInEx/plugins/UnicornAPI/UnicornAPI.dll`). Путь к `UnicornAPI.dll` можно указать отдельно: `-p:UnicornApiDll=...`. Готовый файл: `bin/Release/net6.0/KeycardAnywhere.dll`. DLL игры в репозиторий не входят.
